Before you begin

Common questions.

Do I need to install Python?

Only if Python 3.12 is not already installed. Marginalia reuses an existing installation. On Windows, the launcher asks permission before installing Python through winget; on macOS and Linux, it tells you what is needed. Marginalia then creates an isolated environment inside its own folder.

Do I need Ollama or an AI model?

No. BM25 keyword search works without Ollama. Semantic search and generated answers are optional, and you choose each model separately.

Will it modify my Zotero or Obsidian library?

No. Marginalia creates and searches private working copies. Your source folders remain untouched.

Does it support macOS and Linux?

Yes. The same ZIP contains launchers for Windows, macOS and Linux. The application code is shared; only the small start file differs. Python 3.12 and Tk are required. The launcher guides you if they are missing.

Windows warned me about the download. What should I do?

Marginalia is a new, unsigned open-source project, so Windows may show a reputation warning. Download only from the official GitHub release linked on this page. You can inspect the source and verify the SHA-256 checksum shown above.

How do I update my library later?

Use Refresh library in the left sidebar. Marginalia scans the selected sources again and updates its private copies and all previously active embedding indexes.
