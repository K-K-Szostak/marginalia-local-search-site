First run, step by step

No technical setup required.

Follow these screens. Your first start needs an internet connection; later keyword searches work offline.

01

Download and unpack

Start with one ZIP file.

  1. Download Marginalia-Windows-v0.1.0-beta.2.zip.
  2. Right-click the downloaded ZIP and choose Extract All.
  3. Open the extracted folder and double-click Start Marginalia.cmd.
  4. If Python 3.12 is missing, read the prompt and approve its official installation. A compatible existing Python is reused.
  5. Wait for Marginalia to open automatically in your web browser.

Estimated hardware requirements

Choose the experience that fits your computer.

These are practical estimates, not hard limits. Library size, PDF count and the models you select all affect storage and speed.

Search without AI 8 GB RAM

2+ CPU cores · SSD recommended · no dedicated GPU

Start with at least 3 GB for the application and indexes, then add space for a private working copy of your selected Zotero PDFs and Obsidian notes. Large libraries need more.
Semantic search · Qwen 0.6B 8–16 GB RAM

Modern 4-core CPU · SSD strongly recommended · GPU optional

The suggested Qwen model downloads about 639 MB. Its separate semantic index grows with the number of searchable passages.
Local answers · Gemma 4 12B 16 GB minimum
24 GB recommended

Recent multi-core CPU · dedicated GPU optional

Gemma 4 12B downloads about 7.6 GB. CPU-only answers work but can be slow; about 10–12 GB VRAM is a useful target for mostly-GPU inference.

Disk planning: free space should cover the application, chosen Ollama models, generated indexes and a working copy of selected source files. Your originals remain untouched.

02

Choose your sources

Connect only what you want.

Select your Zotero data folder, your Obsidian vault, or both. Marginalia reads them to create separate private copies; it does not edit your original folders.

  • Zotero and Obsidian are independently optional
  • Folder locations can be changed later
  • No documents are uploaded to a cloud service
03

Let Marginalia prepare

See exactly what is happening.

The progress window reports the current file, completed stages, time spent and whether local AI uses your CPU or GPU. If interrupted, completed preparation stages are preserved and the semantic index can resume.

Large libraries take time on the first run. Later refreshes reuse unchanged work wherever possible.

Optional local AI

You decide what gets installed.

Skip AI completely, or add it during setup or later from AI models. Marginalia can start Ollama when needed.

  • Qwen3 Embedding 0.6B — suggested lightweight semantic search model
  • Gemma 4 12B — optional model for generated answers
  • Advanced users may add other Ollama embedding or answer models

Each embedding model gets its own index and a visible build progress bar.

A quieter kind of software

Your library stays your library.

Marginalia works from private copies and never writes into the Zotero or Obsidian folders you selected. There is no account to create and no document upload step.

If you enable AI, Ollama runs the selected models locally. If you do not, ordinary BM25 search remains fully available.

Before you begin

Common questions.

Do I need to know Python?

No. Double-click Start Marginalia.cmd. If the required Python version is missing, Marginalia explains the situation and asks for permission before attempting an official installation. It will not silently install anything.

What if Python is already installed?

Marginalia reuses a compatible Python 3.12 installation. It then creates an isolated environment inside its own folder so the application does not modify your other Python projects.

Do I need Ollama or an AI model?

No. BM25 keyword search works without Ollama. Semantic search and generated answers are optional, and you choose each model separately.

Will it modify my Zotero or Obsidian library?

No. Marginalia creates and searches private working copies. Your source folders remain untouched.

Does it support macOS or Linux?

Not in this beta. The downloadable package currently supports Windows 10/11 on 64-bit PCs. macOS and Linux packages are planned, but are not available yet.

What computer do I need?

For ordinary BM25 search, an x64 Windows 10/11 computer with 8 GB RAM, at least two CPU cores and an SSD is a sensible baseline. The lightweight Qwen embedding model is comfortable with 8–16 GB RAM. Local answers with Gemma 4 12B need about 7.6 GB just for the downloaded model; 16 GB RAM is the practical minimum and 24 GB is recommended. A GPU is optional but can make local AI much faster.

Windows warned me about the download. What should I do?

Marginalia is a new, unsigned open-source project, so Windows may show a reputation warning. Download only from the official GitHub release linked on this page. You can inspect the source and verify the SHA-256 checksum shown above.

How do I update my library later?

Use Refresh library in the left sidebar. Marginalia scans the selected sources again and updates its private copies and all previously active embedding indexes.
